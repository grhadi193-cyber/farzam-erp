# پنل ERP فرزام — نسخه مستقل سروری (Farzam ERP Server)

نسخهٔ مستقل و قابل نصب روی سرورِ پنل مالی فرزام: یک وب‌اپلیکیشن فارسی و راست‌چین که کارمندها رویدادهای مالی را با **یک پیام آزاد** («خریدیم…»، «فروختیم…»، «حقوق فلانی…») ثبت می‌کنند و ایجنت (Pip) از طریق API اختصاصی خودش آن‌ها را طبقه‌بندی و در دفتر درست ثبت می‌کند.

- **واحد پول:** ریال (مبالغ صحیح)
- **تاریخ‌ها:** رشتهٔ شمسی (مثل «۱۴۰۵/۰۹/۰۲»)، دقیقاً مثل شیت‌های قبلی
- **پشته:** Node.js + Express، دیتابیس SQLite تک‌فایلی (`data/farzam.db`)، احراز هویت JWT — بدون مرحلهٔ بیلد برای فرانت‌اند

## نصب سریع (Docker — راه پیشنهادی)

```bash
cp .env.example .env
# مقادیر .env را ویرایش کنید: ADMIN_EMAIL ،ADMIN_PASSWORD ،JWT_SECRET ،PIP_AGENT_API_KEY
docker compose up -d --build
```

بعد مرورگر را باز کنید: **http://localhost:3000**

اولین ورود با همان `ADMIN_EMAIL` / `ADMIN_PASSWORD` داخل `.env` است (کاربر مدیر در اولین اجرا به‌صورت خودکار ساخته می‌شود).

## نصب بدون Docker (Node.js 18+)

```bash
cp .env.example .env   # و ویرایش مقادیر
npm install
npm start              # http://localhost:3000
```

## متغیرهای محیطی (.env)

| متغیر | توضیح |
|---|---|
| `PORT` | پورت سرور (پیش‌فرض ۳۰۰۰) |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` | حساب مدیر اولیه (فقط در اولین اجرا ساخته می‌شود) |
| `ADMIN_NAME` | نام نمایشی مدیر (اختیاری) |
| `JWT_SECRET` | راز امضای توکن‌های ورود — یک رشتهٔ تصادفی بلند |
| `PIP_AGENT_API_KEY` | کلید API ایجنت Pip (هدر `Authorization: Bearer <key>`) |
| `SEED_DEMO` | اگر `true` باشد چند ردیف آزمایشیِ برچسب‌خورده با «نمونه» ساخته می‌شود (پیش‌فرض: خاموش) |

## نقش‌ها

| نقش | دسترسی |
|---|---|
| `admin` مدیر | همه‌چیز + ساخت کاربر |
| `finance` مالی | ثبت و ویرایش دفاتر، دفاتر کل، داده‌های پایه، دانش + طبقه‌بندی رویدادها |
| `employee` کارمند | ساخت رویداد ورودی + مشاهده |
| `viewer` مشاهده‌گر | فقط مشاهده |

نوشتن در دفاتر فقط برای مدیر و مالی است؛ ساخت رویداد برای کارمند هم باز است.

## ماژول‌ها

- **داشبورد:** جمع درآمد/هزینه/حقوق، خالص، نمودار میله‌ای و دونات دسته‌های هزینه، شمارش رویدادهای نامشخص
- **ورودی یکپارچه:** فهرست رویدادها با دکمهٔ طبقه‌بندی (هزینه/درآمد/حقوق/نامشخص) — طبقه‌بندی، ردیف دفتر متناظر را می‌سازد
- **دفاتر:** هزینه‌ها، درآمدها، حقوق (ثبت + تغییر وضعیت بررسی)
- **دفاتر و چک‌ها:** دریافتنی، پرداختنی، چک (با شمارهٔ صیادی)
- **داده‌های پایه:** مشتری‌ها و کالاها
- **دانش و قوانین:** قواعد، پاسخ‌های مدیریت و یادداشت‌ها

## دسترسی ایجنت (Pip)

ایجنت با صفحهٔ وب کار نمی‌کند؛ از API زیر `/api/agent/*` با کلید جدا استفاده می‌کند و **هر نوشتن ایجنت در جدول `audit_log` ثبت می‌شود**. جزئیات: [docs/agent-api.md](docs/agent-api.md) و [docs/access-for-pip.md](docs/access-for-pip.md).

## وبهوک تلگرام

`POST /api/telegram/webhook` آپدیت تلگرام را می‌گیرد (متن/کپشن + `file_id` عکس) و به‌صورت یک رویداد پردازش‌نشده ذخیره می‌کند. هیچ تماس خروجی به تلگرام زده نمی‌شود؛ آدرس وبهوک را با BotFather یا `setWebhook` روی همین مسیر تنظیم کنید.

## داده و بکاپ

همه‌چیز در `data/farzam.db` است (در Docker روی ولوم `./data` ماندگار می‌ماند). برای بکاپ کافی است همین فایل کپی شود. فایل دیتابیس، `.env` و `node_modules` در `.gitignore` هستند و وارد گیت نمی‌شوند.

## امنیت

- هیچ رازی در کد نیست؛ همه از `.env` خوانده می‌شود و `.env` نباید کامیت شود.
- کلید ایجنت را در چت نفرستید؛ از مسیر امن اتصال Muse تحویل دهید (نگاه کنید به docs/access-for-pip.md).
- پشت HTTPS (دامنه + reverse proxy) اجرا کنید و `JWT_SECRET` و کلید ایجنت را تصادفی و بلند انتخاب کنید.
